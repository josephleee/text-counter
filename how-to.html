사용 방법

글자수 세기 도구의 모든 기능을 쉽고 빠르게 활용하는 방법을 알려드립니다.

기본 사용법

1
텍스트 입력 텍스트 영역에 내용을 입력하거나 붙여넣기(Ctrl+V / Cmd+V)하세요. 글자를 입력하는 즉시 모든 통계가 실시간으로 업데이트됩니다.
2
통계 확인 상단 통계 카드에서 공백 포함 글자수, 공백 제외 글자수, 단어수, 문장수, 문단수, 예상 읽기 시간을 한눈에 확인하세요.
3
글자수 제한 확인 각 플랫폼별 글자수 제한(네이버 블로그 5000자, 인스타그램 2200자, 트위터 280자, SMS 80자)을 초과하면 숫자가 빨간색으로 표시됩니다.
4
결과 복사 '복사하기' 버튼을 클릭하여 입력한 텍스트를 클립보드에 복사하세요. 변환된 텍스트도 함께 복사됩니다.

텍스트 변환 기능

입력된 텍스트의 대소문자를 손쉽게 변환할 수 있습니다.

  • 대문자 : 모든 영문 알파벳을 대문자로 변환합니다.
  • 소문자 : 모든 영문 알파벳을 소문자로 변환합니다.
  • 제목 케이스 : 각 단어의 첫 글자를 대문자로 변환합니다.
  • 문장 케이스 : 각 문장의 첫 글자를 대문자로 변환합니다.

변환 버튼을 클릭하면 텍스트 영역의 내용이 즉시 변경되며, 변경된 텍스트를 '복사하기' 버튼으로 클립보드에 복사할 수 있습니다.

읽기 시간 계산 방법

읽기 시간은 다음 기준으로 계산됩니다:

  • 한국어 : 분당 약 500자 기준으로 계산
  • 영어 : 분당 약 200단어 기준으로 계산

한국어와 영어가 혼합된 텍스트의 경우, 두 기준 중 더 오래 걸리는 시간을 표시합니다.

팁 : 500자는 한국 성인의 평균 읽기 속도로, 블로그 포스팅의 적정 길이를 판단하는 데 유용합니다.

추가 통계 활용하기

기본 통계 외에도 다음과 같은 세부 정보를 확인할 수 있습니다:

  • 가장 긴 단어 : 입력된 텍스트에서 가장 길이가 긴 단어를 표시합니다.
  • 가장 많이 사용된 문자 : 가장 빈번하게 등장하는 문자와 사용 횟수를 보여줍니다.
  • 한글/영문/숫자 개수 : 각각의 글자 종류별 개수를 별도로 확인할 수 있습니다.
  • 공백 개수 : 텍스트 내 공백(스페이스, 줄바꿈 등)의 총 개수를 표시합니다.

플랫폼별 글자수 제한 안내

각 SNS 및 블로그 플랫폼의 글자수 제한을 실시간으로 확인하며 콘텐츠를 작성하세요.

  • 네이버 블로그 : 본문 최대 5,000자 (글자수 제한이 가장 중요한 플랫폼)
  • 인스타그램 : 캡션 최대 2,200자
  • 트위터(X) : 트윗 최대 280자
  • SMS : 문자 메시지 최대 80자 (한글 기준 1건)
팁 : 글자수가 제한을 초과하면 해당 항목의 숫자가 빨간색으로 표시됩니다. 초과된 글자수만큼 줄여서 작성해보세요.
